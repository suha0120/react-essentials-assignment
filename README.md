# React Mini Projects

A simple React application containing two mini projects:

- 📇 Portfolio Card
- 🎬 Movie Explorer

---

## Features

### Portfolio Card

- Profile card with image
- Dark/Light theme toggle
- Skills displayed as badges
- Multiple profile photos
- Previous & Next image navigation
- Like counter
- Contact button

### Movie Explorer

- Search movies
- Display movie cards
- Responsive layout
- Clean and simple UI

---

## Technologies Used

- React.js
- JavaScript (ES6)
- CSS3
- HTML5

## Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd project-folder
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```
